# 0.1.0 Debian 13 Artifact Verification

`0.1.0-dev.2` establishes the trusted artifact-resolution contract for the first Debian 13 Standard driver slice.

## Trust chain

AegisPXE resolves Debian 13 amd64 installer artifacts from the official Debian archive using this chain:

1. fetch `https://deb.debian.org/debian/dists/trixie/InRelease`,
2. verify the clear-signed release metadata with `/usr/bin/gpgv` and `/usr/share/keyrings/debian-archive-keyring.gpg`,
3. require `Codename: trixie` and a Debian `13.x` release version,
4. read the trusted SHA-256 identity and byte size of `main/installer-amd64/current/images/SHA256SUMS`,
5. resolve `current` to the unique versioned installer manifest with the same signed digest and size,
6. fetch that versioned `SHA256SUMS` and verify it against the signed release metadata,
7. read the expected SHA-256 identities for `netboot/debian-installer/amd64/linux` and `initrd.gz`,
8. fetch both artifacts from the versioned installer path and verify their content before returning them as usable artifacts.

The moving `current` path is never stored in an InstallationSpec. The spec pins the versioned source URL, installer version, SHA-256 digest, byte size and provenance string.

## Fail-closed rules

- An invalid Debian archive signature is `ART001_ARTIFACT_TRUST_FAILED`.
- Missing, ambiguous or malformed trusted release/checksum metadata is `ART001_ARTIFACT_TRUST_FAILED`.
- A checksum-manifest or installer-artifact digest mismatch is `ART002_ARTIFACT_HASH_MISMATCH`.
- A bounded network fetch failure is `ART003_ARTIFACT_FETCH_FAILED`.
- HTTP redirects may not leave the fixed `https://deb.debian.org` origin.
- Responses are size-bounded before they are accepted.
- `gpgv` is invoked directly with fixed arguments. No shell or caller-controlled executable/keyring path is exposed.

## Package requirements

The Debian package depends on `gpgv` and `debian-archive-keyring` so the runtime trust anchor is supplied through the OS package system rather than downloaded by AegisPXE.

## Scope boundary

This slice resolves and verifies trusted Debian installer bytes and metadata. It does not yet:

- persist/cache verified installer binaries,
- render an iPXE installation boot script,
- create or arm an installation through an administrative API,
- render unattended installer configuration,
- issue lifecycle credentials.

Those operations build on the verified immutable artifact descriptors established here.
