# 0.1.0-dev.12 stabilization follow-up

This follow-up is driven by the first successful end-to-end Debian 13 installation after dev.11.

Observed results:

- Debian installation completed successfully after the late-command quoting fix.
- A network-first reboot re-entered the same installer because the destructive assignment remained `armed`.
- Studio HTML had already moved to the richer desktop layout, while a cached older stylesheet could leave new markup visibly unstyled.
- machine-correlated logs belong on the Machine detail surface, not on the Dashboard overview.

Changes in this slice:

- destructive public boot assignments become one-shot at the final Preseed handoff;
- assignment consumption remains scheduling state and does not invent installer lifecycle success;
- the next PXE discovery falls back to local boot because no armed assignment remains;
- Studio CSS/JS is revalidated instead of being cached across incompatible markup changes;
- the Dashboard no longer surfaces the generic Recent activity panel;
- Machine details receive a recent, live, redacted structured-log panel filtered by `machine_id`;
- cryptographic boot trust and authenticated installer telemetry remain future 0.1.0 RC requirements.
